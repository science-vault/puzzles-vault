# Puzzles Vault

A standalone classroom puzzle catalogue organised by learning area, subject, year, strand and topic.

`dist/catalogue.json` contains one record per puzzle. Each record links to a worksheet PDF in `dist/resources` and optionally to an answer booklet with its page number. Keep resource URLs relative to `dist` and use individual year values in the `years` array. The Science Puzzles pack uses suggested WA year placements.

The live catalogue is available at https://puzzles-vault.jjdcruz27.chatgpt.site/. The catalogue uses repository-relative PDF paths. Preview images for newer puzzle collections are served by the live site. Year placements are suggested WA curriculum matches.
